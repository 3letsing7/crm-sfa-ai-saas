# システム概要

## システム名

AI営業支援CRM/SFA

---

# 目的

本システムは、IT企業向けのCRM/SFA SaaSである。

顧客管理、商談管理、営業活動管理を行い、
営業業務の効率化を目的とする。

また、共P-01（顧客対応・販売支援）に対応する。

---

# 想定ユーザー

- IT企業
- ソフトウェア会社
- 営業担当者
- 営業マネージャー

---

# MVP範囲

初期MVPでは以下を実装する。

- ログイン
- 顧客管理
- 商談管理
- 活動履歴
- ダッシュボード

AI機能はPhase2で実装する。
